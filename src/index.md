## 米奇妙妙屋想解决什么？

AI 不会替你判断对错。Vibe Coding 时代，缺少跨岗位基础的人，最容易被 AI 的幻觉牵着走——越用越累，返工越多。

所以这里按 计算机基础 → 运维 → 后端 → 测试 → AI 应用 → 产品 → 架构 → 前端 → UI 排了一条学习路线：先把全流程看懂，再用 AI 放大自己的产出，而不是让它替自己思考。

开发编码只占正规项目的 20%，AI 至今没能高质量完成工程，本质仍是黑盒祈祷编程。与其追 Harness、Skills 这类几个月迭代一次的中间产物，不如把精力放在企业级规范开发流程上——推荐阅读 [Agent 工作流](/workflow/)。
