# 写笔记说明

## 目录结构

```text
blog/src/notes/
├─ 00-计算机基础/
│  ├─ 01-数据结构/
│  │  ├─ 01-绪论.md
│  │  ├─ 02-线性表.md
│  │  └─ assets/            # 本篇/本章图片
│  ├─ 02-计算机组成原理/
│  └─ ...
├─ 01-产品/
└─ 08-AI/
```

- 第一层是方向（`00-` 到 `08-`），第二层是章节，第三层是具体笔记
- **数字前缀不能省**：侧边栏与 `/notes/` 都按文件名的数字顺序排序
- 新增方向或章节，直接建目录即可，不用改配置

## 新建一篇笔记

1. 在对应章节下新建 `NN-标题.md`，比如 `09-新章节/03-缓存设计.md`
2. 文件开头写 frontmatter：

```yaml
---
title: 缓存设计
date: 2026-10-28
category: 架构
tags:
  - 缓存
  - 性能
---
```

3. 正文从二级标题开始，主题会自动生成右侧「此页内容」：

```md
## 为什么需要缓存

……

### 缓存的几种形态

……
```

4. 保存后开发服务器热更新；侧边栏与 `/notes/` 目录页会在下次 `dev` / `build` 时刷新

## 图片

放在笔记同级的 `assets/` 目录，用相对路径引用：

```md
![示意图](./assets/示意图.png)
```

- 单文件不要超过 25 MiB（Cloudflare 限制）
- 截图建议压缩到 200 KB 以内，仓库体积主要来自图片
- 同一章节共用的图放章节的 `assets/`，只有一篇用到的放该篇旁边也可以

## 不要手改的文件

| 文件 | 说明 |
| --- | --- |
| `blog/src/notes/index.md` | 由 `scripts/gen-notes-index.mjs` 生成，改脚本而不是改产物 |
| `blog/src/.vuepress/sidebar.ts` 生成的目录 | 侧边栏配置本身可改，但目录清单来自磁盘，不需要手写 |
| `blog/src/.vuepress/dist/` | 构建产物，不提交 |

## 常用语法

站点已启用这些 Markdown 增强：

- Mermaid 图表：```` ```mermaid ```` 代码块
- 数学公式：`$...$` 与 `$$...$$`
- 提示块：

```md
::: tip
提示内容
:::

::: warning
注意事项
:::
```

- 图片尺寸：`![图](./assets/x.png =300x)` 指定宽度
