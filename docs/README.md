工作流模板是给「有后端、有数据库、有外部系统」的项目准备的。这个站点是**纯静态发布端**，下面这些模板位置不产出文件，原因是结构上不存在对应实体：

| `03-架构/06-ER图/` | 无表结构 |
| `03-架构/03-状态机/` | 无带 `status` 列的实体 |
| 全部 `deploy/` 与 `deploy/env/` | 部署完全托管在 Cloudflare Pages，仓库内只有 `blog/wrangler.jsonc` 一个备用配置 |

**`07-ADR重要决策/` 不在上表里**——它有三份：`ADR1` 内容源与站点分离、`ADR2` 主题选型、`ADR3` 不用数据库。三条都是改变后续所有决定的选型，都有替代方案与否决理由。
