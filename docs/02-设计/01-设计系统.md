# 设计系统

> **放行**：已放行 · JimBo · 2026-11-22
> **最后更新**：2026-11-22

> 本项目**不用 OpenDesign 的设计系统**。原型由 OpenDesign 生成，但视觉令牌全部来自现有站点的 CSS，不是某套预设设计系统。
> 这是登记表，不是定义表——令牌的唯一事实源是 `blog/src/.vuepress/styles/` 与构建产物 CSS。

## 一、用的哪一套

| 项 | 值 |
|---|---|
| 设计系统 ID | **无**（`designSystemId: null`） |
| 名称 | 自建视觉规范：绿蓝紫渐变 + 极光背景 + 玻璃卡片 |
| 为什么不用预设 | 站点已上线且视觉定稿，换成任何一套预设都会推翻现有外观。原型是复刻，不是重设计 |
| 有没有定制 | 全部定制：主色、渐变、背景、卡片材质都是自己定的 |
| 生成工具 | OpenDesign（skill `frontend-design`，agent `amr`），brief 见 `docs/99-tmp/设计-原型/brief.md` |

## 三、与通用的偏差

**全部偏差，没有「通用」可言。** 本项目没有引入任何预设设计系统，所以不存在「与预设的偏差」——所有令牌都是一次次调出来的。

两条值得记下的取舍：

| 取舍 | 理由 |
|---|---|
| 主色用绿而不是蓝 | 文档站常用蓝，绿色在这个站上更不像「又一个技术博客」，且与极光的绿团呼应 |
| 渐变固定三色三段（绿→蓝→紫） | 三色都在同一段色相区间，过渡不显杂乱；只变色相不改明度，深浅色两套只需换色调 |

## 四、换设计系统时

**不要换。** 站点视觉已经定稿并上线，换设计系统意味着推翻首页、卡片、渐变、侧边栏的全部样式。

真要换时的顺序：

1. 改 `blog/src/.vuepress/styles/palette.scss` 与 `index.scss`
2. 改 `blog/src/.vuepress/theme.ts` 里与主题相关的项（深浅色、页脚、图标）
3. 重新生成原型（`docs/99-tmp/设计-原型/brief.md` 里的「视觉规范」一节要同步改）
4. 页面规格跟着更新

**不要在旧产物上打补丁。** 重新生成比修补便宜，这是设计岗的硬规则。
