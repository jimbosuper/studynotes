## 七、三个内容栏目的形态

三个栏目都按「先定结构与规则、内容分批填」上线，所以页面在任何时候都不空：

| 页面 | 形态 | 内容怎么补 |
|---|---|---|
| `/projects/` | `00-内容导读` + 项目目录。每个项目一个目录，下分七个角色；文档由 `docs/` 镜像生成，可交互产物用 iframe 内嵌 | 每完成一个项目追加一个 `NN-项目名` 目录 |
| `/resources/` | 4 行分类表（开源项目 / 代码规范 / 学习文档 / 实用网站）+ 三条收录规则 | 每类按规则逐批收条目 |
| `/methods/` | 8 个认知模型的目录与入口 | 每个模型一篇正文，逐篇补 |

**页面结构不随内容变**：新增条目、新增项目、新增正文都只动数据，不动布局与样式。这是三个栏目共用的一条约束。

## 九、验收记录

**产物**：`02-原型图/index.html`（OpenDesign 生成，1,532 行，56 KB，单文件自包含）

| 项 | 通过标准 | 实测 |
|---|---|---|
| 屏数 | 与 brief 的 4 屏一致 | `data-screen` 命中 `home / notes / workflow / note` 四个 ✅ |
| 屏切换 | 四屏互切可用 | 浏览器实测点「笔记目录」「工作流目录」「笔记正文」均切换成功 ✅ |
| 深浅/宽度开关 | 桌面 1440 与手机 375 可切 | 两个开关都在顶部工具条，手机模式下侧栏消失 ✅ |
| 首页卡片 | 12 张，与真实站点同文案 | 12 个 `<h3>` 标题逐字核对，与线上一致 ✅ |
| 首页导航 | 6 项，顺序固定 | `首页 / 全栈笔记 / 全栈项目 / Agent工作流 / 优质资源 / 学习方法` ✅ |
| 笔记目录页 | 总览表 + 明细表 | 3 张表、28 行 `<tr>`；总览 10 行 + 合计，明细含 `00-计算机基础` 与 `05-后端` 三层展开 ✅ |
| 工作流目录页 | 7 行 4 列 | 1 张表、8 行 `<tr>`（表头 + 7 行）✅ |
| 正文页 | 引用块 + 版本表 + 代码块 | 1 张表 4 行；代码块与版本表数据与线上一致 ✅ |
| 侧边栏首项 | `00-内容导读` 在 10 方向之前 | 笔记目录页与工作流页都在首位 ✅ |
| 自包含 | 无外链 CSS/JS 字体 | `grep` 外链 0 处；图片 0 张（头像画成内联渐变色块）✅ |
| 令牌一致 | 与 `01-设计系统.md` 摘的值相同 | 主色 `#2f845d`、渐变 92deg 三色、极光三团、玻璃卡片参数逐值核对 ✅ |
| 手机宽度 | ≤620px 隐侧栏与右目录、卡片单列 | 用 container query 实现（`@container (max-width: 620px)`），不靠窗口缩放 ✅ |

**四条取舍，与 brief 有出入但不影响复刻准确度：**

| 项 | brief 要求 | 实际做的 | 为什么接受 |
|---|---|---|---|
| 断点 | 375px 手机宽度 | 用**容器查询** `@container (max-width: 1180px / 900px / 620px)` 三档 | 窗口缩放测不出响应式，容器查询能在同一窗口内真实生效，比 brief 写的更强 |
| 方向卡片图标 | 未指定 | 统一描边内联 SVG，不是 emoji | 与线上 fontawesome 的线性风格一致 |
| 头像 | 220×220 | 内联渐变色块，不引 `avatar.png` | 单文件自包含的代价；形状与圆角一致 |
| Mermaid | 正文页要体现 | 留一块 96px 高的骨架条，不画假图 | 编一张假图等于给下游假信息 |

**覆盖边界**：原型按 1440 与 375 两档出，1512 / 1920 沿用 1440 的断点规则；Mermaid 在原型里是 96px 骨架，真实渲染以线上正文页为准。
