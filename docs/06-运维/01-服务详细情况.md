# 服务详细情况

> **最后更新**：2026-11-22

**本项目只有一个服务：一个静态站点。** 没有后端、没有数据库、没有中间件、没有定时任务。

| # | 服务 | 类型 | 状态 | 地址 |
|---|---|---|---|---|
| 1 | 妙妙屋站点 | 静态站点（CDN 托管） | 生产运行中 | `https://studynotes-90w.pages.dev` |

| 项 | 值 |
|---|---|

## 二、生产环境服务情况

**只有生产一套环境，没有测试环境。** 本地开发即「测试」，详见 `03-架构/04-项目环境规范.md`。

| 项 | 值 |

### 2.2 部署拓扑

拓扑图在 `02-部署拓扑.html`（**手写 SVG 自包含**，不是 Archify 产物：部署拓扑只有 7 个节点、三段链路，画一张 Archify 图再套模板不划算，直接用 SVG 更可控）。文字版：

```text

   ▼
```

**没有中间层。** 读者直接访问 CDN，不经过任何自建服务。

### 2.3 依赖与失效影响

| 依赖 | 用途 | 挂了会怎样 | 能做什么 |
|---|---|---|---|
| GitHub | 存放代码与触发构建 | 无法发布新版本；**线上旧版仍可访问** | 等待恢复；本地构建产物手工上传（Cloudflare 支持直传） |
| Cloudflare Pages | 构建 + 托管 + CDN | 站点不可访问 | 无替代托管（未配置备份） |
| 域名 | `studynotes-90w.pages.dev` 由 Cloudflare 签发 | 站点不可访问 | 绑定自定义域名可换，需改 `theme.ts` 三处 |
| 两个内容源仓库 | 内容来源 | **不影响线上**（产物已提交）；只影响本地 sync | 本地已有产物，可直接构建 |

**关键判断：内容源仓库不是生产依赖。** 线上只跑 `npm run build`，不跑 `sync`。源库挂了，站点照常服务。

### 2.7 配置基线

| 项 | 值 |
|---|---|
| Production branch | `master` |
| Root directory | `blog` |
| Build command | `npm run build` |

**没有任何密钥。** 没有 API token、没有数据库密码、没有第三方服务凭证。

## 三、故障处理与恢复

| 故障 | 判断方法 | 恢复动作 |
|---|---|---|
| 站点 404 | 访问根路径看状态码 | 查 Cloudflare Pages 的 Deployments，最近一次是否失败；是则修代码重推 |
| 页面内容缺一半 | 打开具体页，只显示开头几句 | Vue 语法冲突（裸 `{{ }}`）；本地 `npm run sync` 会修，重新构建推送 |
| 图片全裂 | 打开任一笔记页看 `dist/assets/` 是否 404 | 检查 `src/notes/**/assets/` 是否随同步提交 |
| 发布失败但本地成功 | 对比构建日志 | 最常见是忘了提交同步产物；其次 `.DS_Store` 混入 |
| 部署后旧内容 | 打开页面看到上一版 | 确认推的是 `master`；确认提交里含 `blog/src/notes/` |

**回滚方式**：Cloudflare Pages → Deployments → 找到上一个成功的 → `Rollback`。**不需要改代码**。

## 四、交接

接手的人需要知道这五件事：

1. **改内容去源库，不改 `blog/src/notes/`** —— 那里是同步产物
2. **线上不跑 sync** —— 内容必须先本地同步并提交
3. **`C++` 必须改名 `Cpp`** —— 同步器会自动做，手改要自己记得
4. **只剩一种错误会阻断发布** —— 裸 `{{ }}` 与裸尖括号
5. **回滚不用改代码** —— Cloudflare 的 Deployments 面板点 Rollback

完整命令与约定见 `README.md` 与 `AGENTS.md`。
