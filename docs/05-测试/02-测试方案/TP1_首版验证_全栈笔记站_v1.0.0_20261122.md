# 全栈笔记站 · 首版验证

## 一、测什么

这次是从零建站，要证明五件事：

1. **五个栏目都能进得去**，没有空链接、没有 404
2. **笔记能三层下钻**：首页 → 方向 → 章节 → 篇
3. **侧边栏与磁盘目录一致**，新增笔记不用改配置
4. **首页视觉到位**：标题、定位、方向入口、配色、深浅色
5. **构建与体积在限内**，能上线

**不测**：笔记正文的技术正确性（属内容源仓库职责）、浏览器兼容（未承诺）。
