# 米奇妙妙屋 · 项目主页

一个个人全栈知识库站点。**219 篇技术笔记 + 7 份 Agent 工作流文档**，纯静态发布，无后端、无数据库。

从「只有一堆散在本地仓库的 Markdown」到「一个能按方向逐层浏览、能全文检索、手机能读、推一次代码就自动上线」的站点——已上线运行。

## 这个项目证明什么

| 项 | 内容 |
| --- | --- |
| 链路 | 产品 → 设计 → 架构 → 开发 → 测试 → 运维 → 审查，**七个角色各留了产物** |
| 规模 | 365 页 / 1,841 个产物文件 / 235 MB |
| 技术栈 | VuePress 2 + vuepress-theme-hope 2 + Vite，托管在 Cloudflare Pages |
| 验证 | 构建 0 错误、5,518 条站内链接 0 死链、23 条测试用例全过 |
| 决策 | 3 份 ADR：内容源分离、主题选型、不用数据库 |
