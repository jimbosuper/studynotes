# 学习方法

这一节写**怎么学**，不是学什么。

> **这一栏收 8 个认知模型**：学习金字塔、布鲁姆认知层级、费曼学习法、西蒙学习法、学习区理论、目标学习法、SQ3R 阅读法、刻意练习。每一篇独立成页，不合并成一篇长文。

## 和笔记的关系

学习方法决定**怎么读**，[全栈笔记](/notes/) 决定**读什么**。先看 [00-内容导读](/notes/00-内容导读.html) 里的四条路线，再决定用哪种方法去读。

## 正文清单

| # | 方法 | 回答的问题 |
| --: | --- | --- |
| 01 | 学习金字塔 | 被动听和主动讲，留存量差多少 |
| 02 | 布鲁姆认知层级 | 记住、理解、应用、分析、评价、创造，六层怎么往上走 |
| 03 | 费曼学习法 | 讲不明白的地方，就是没懂的边界 |
| 04 | 西蒙学习法 | 六个月内能不能学会一个领域 |
| 05 | 学习区理论 | 太难与太易都不长本事，难度该落在哪 |
| 06 | 目标学习法 | 先定输出目标，再倒推学什么 |
| 07 | SQ3R 阅读法 | 读一篇长文怎么不白读 |
| 08 | 刻意练习 | 有反馈的重复，和无反馈的重复差在哪 |

**每篇独立成页**，按同一结构写：它解决什么问题、怎么落到一次具体的学习动作、什么情况下不要用。
