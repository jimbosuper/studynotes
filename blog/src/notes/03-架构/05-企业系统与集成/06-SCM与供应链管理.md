# SCM 与供应链管理

## 一、工程案例：把“缺料停产”变成可预测的风险

**场景**：一家离散制造企业，采购员每天接 50 个催料电话。计划员用 Excel 做 MRP，物料到货时间靠供应商口头承诺。旺季来了，缺料导致停线三天；淡季来了，库存积压 8000 万。供应商有 300 家，绩效没人算，付款还要催发票。老板要求：缺料停线时间降到每月 4 小时内，库存周转从 45 天降到 30 天，供应商准时交付率到 95%。

**目标**：不推翻 ERP，先把 SCM 的预测、协同、物流、绩效模型定清楚，交付：

- 一张 SCM 功能地图；
- 一套需求预测与 S&OP 机制；
- 一张供应商协同（SRM）与寻源流程；
- 一套物流与运输管理要点；
- 一张供应商绩效模型；
- 一份与 ERP、WMS、MES、BI 的集成清单；
- 一份验收清单（8 项）。

**为什么必须做**：供应链的问题很少是“某个环节坏了”，而是“计划、采购、物流、库存四者之间没有闭环”。SCM 的价值不是“管供应商”，而是“让需求、供给、库存、风险在同一套数据下决策”。

**动手前确认**：先拉三样东西：最近 12 个月的物料消耗与到货记录、库存周转天数、停线记录与原因。没有这三样，供应链优化只能凭感觉。下面的企业数据是示例。

### 1.1 SCM 的边界

| SCM 管 | SCM 不管 |
|---|---|
| 需求预测、S&OP | 主生产计划排程细节 |
| 寻源、招标、供应商管理 | 应付账款核算 |
| 采购协同、订单跟踪 | 车间领料作业 |
| 物流、运输、运费结算 | 仓库库位作业 |
| 库存优化、安全库存策略 | 财务库存过账 |
| 供应商绩效、风险 | 供应商合同法务审批 |

SCM 是“跨企业的供需协同层”。它向上接需求，向下接采购与物流，横向连库存和生产。把 SCM 当“采购系统”，会丢掉最有价值的预测和协同能力。

### 1.2 功能地图

| 模块 | 核心功能 | 关键对象 | 常见问题 |
|---|---|---|---|
| 需求计划 | 预测、S&OP、安全库存 | 预测版本、计划版本 | 预测不准且无人负责 |
| 寻源采购 | 询价、招标、合同、订单 | 询价单、合同、采购订单 | 价格分散，无历史分析 |
| 供应商管理 | 准入、评估、分级、风险 | 供应商、绩效、风险 | 没人算账，好坏不分 |
| 协同 | ASN、订单跟踪、对账 | ASN、交货记录 | 靠邮件和电话 |
| 物流 | 运输计划、承运商、运费 | 运单、运费 | 运费算不清 |
| 库存优化 | 安全库存、补货点、呆滞 | 库存策略、呆滞清单 | 一刀切，全部 30 天 |
| 风险管理 | 单一来源、断供、地缘 | 风险清单、预案 | 出事才想到 |

先做“预测 + 采购协同 + 供应商绩效”三件套，再上高级优化。

### 1.3 需求预测

预测的难点不是算法，是“谁负责、错了怎么办”。

| 预测类型 | 方法 | 适用 |
|---|---|---|
| 统计预测 | 移动平均、指数平滑 | 需求稳定 |
| 因果预测 | 回归、促销因子 | 有明确驱动因素 |
| 定性预测 | 销售判断、客户计划 | 新品、大项目 |
| 协同预测 | 客户共享计划、CPFR | 大客户、长期合作 |

预测要“版本化 + 责任人 + 误差跟踪”：

- 每周一个版本，记录预测值、实际值、偏差；
- 偏差超过阈值要复盘，不是改数字；
- 预测准确率纳入计划和销售的考核。

只统计不考核，预测永远不准。

### 1.4 S&OP

S&OP（Sales & Operations Planning，销售与运营计划）把需求、供给、库存、财务摆到一张桌上。

| 环节 | 输入 | 输出 | 频率 |
|---|---|---|---|
| 数据准备 | 库存、在途、产能、订单 | 统一数据包 | 周 |
| 需求计划 | 销售预测、客户计划 | 需求版本 | 周 |
| 供给计划 | 产能、物料、采购提前期 | 供给能力 | 周 |
| 预会议 | 差异、瓶颈、风险 | 差异清单 | 周 |
| 决策会 | 方案、资源、取舍 | S&OP 决议 | 月 |
| 执行跟踪 | 决议、行动项 | 跟踪表 | 周 |

S&OP 不是“开会”，是“用同一套数据做供需平衡的决策机制”。没有 S&OP，销售、计划、采购各说各话，库存和缺料同时存在。

供应商分级：

| 级别 | 策略 |
|---|---|
| 战略 | 长期合作、联合计划、共享预测 |
| 优选 | 多品类、定期评估、价格年审 |

| 备选 | 应急、小批量 |
| 淘汰 | 逐步退出 |

供应商准入要有硬门槛：资质、产能、质量体系、财务健康度、合规（如环保、劳工）。

### 1.6 协同

供应商协同的核心是“把订单状态从黑盒变透明”：

| 协同内容 | 方式 | 价值 |
|---|---|---|
| 采购订单 | 门户/API/EDI | 减少邮件和电话 |
| 订单确认 | 供应商回执 | 知道对方是否接单 |
| ASN | 发货通知 | 仓库能预约、预分配 |
| 交货跟踪 | 物流节点回传 | 预测到货时间 |
| 对账 | 月度对账 | 减少发票差异 |
| 质量反馈 | 8D/纠正措施 | 持续改善 |

协同不是“上个门户就行”，要有激励：响应快的供应商给更多份额，差的淘汰。没有激励，供应商不会认真维护数据。

### 1.7 物流与运输

| 模式 | 适用 | 关键点 |
|---|---|---|
| 自营车队 | 线路固定、批量大 | 车辆、司机、路线、油耗 |
| 第三方物流（3PL） | 灵活、多区域 | 合同、KPI、运费结算 |
| 零担（LTL） | 小批量、多批次 | 集货、配载 |
| 整车（FTL） | 大批量、直达 | 车源、运费 |
| 多式联运 | 长距离、跨境 | 单据、报关、时效 |
| 跨境物流 | 进出口 | 报关、单据、关税、合规 |

运费管理三件事：计费规则（重量、体积、距离、附加费）、对账（运单 vs 结算）、异常（破损、延误、丢件）。

### 1.8 库存优化

库存不是“越少越好”，是“在服务水平与成本之间找平衡”。

| 策略 | 适用 |
|---|---|
| 安全库存 | 需求/供给波动大 |
| 再订货点 | 需求稳定、提前期固定 |
| 定量/定期补货 | 消耗平稳 |
| VMI/JIT | 供应商近、协同好 |
| 寄售 | 高价值、长周期 |
| 呆滞处理 | 呆滞识别、清理、追责 |

库存分类用 ABC + XYZ：

- ABC：按消耗金额（A 高、C 低）；
- XYZ：按需求稳定性（X 稳定、Z 波动）。

AX 类可降库存，CZ 类要保安全库存。全部用同一策略，一定同时存在缺料和积压。

### 1.9 与 ERP、WMS、MES、BI 集成

| 集成点 | 上游 | 下游 | 内容 | 失败处理 |
|---|---|---|---|---|
| 采购订单 | SCM/ERP | WMS/供应商 | 订单、行、交期 | 重发，幂等键 |
| ASN | 供应商 | WMS | 发货明细、批次 | 缺失则按普通收货 |
| 到货预约 | SCM | WMS | 车辆、时间、月台 | 延迟可接受 |
| 收货 | WMS | ERP/SCM | 收货、批次、数量 | 对账，差异冲正 |
| 消耗 | MES | SCM/ERP | 领料、消耗 | 日汇总对账 |
| 应付 | ERP | SCM | 发票、对账、付款 | 三单匹配 |
| 物流 | SCM/3PL | WMS/客户 | 运单、签收 | 延迟可接受 |
| BI | SCM/ERP/WMS | BI | 交付、库存、成本 | 日批量 |

原则：**采购订单和财务过账以 ERP 为准，协同和物流以 SCM 为准，实物以 WMS 为准**。

### 1.10 供应商绩效

| 维度 | 指标 |
|---|---|
| 交付 | 准时交付率、提前期稳定性 |
| 质量 | 来料合格率、PPM、退货率 |
| 成本 | 价格竞争力、降价达成 |
| 服务 | 响应时间、问题解决 |
| 风险 | 单一来源、财务健康度、合规 |

绩效要“月评分 + 季回顾 + 年淘汰”。只记分不行动，绩效管理就是形式。

### 1.11 验收（8 项）

1. 预测：连续 6 个月，预测偏差 ≤ 20%，偏差有复盘记录。
2. S&OP：月度 S&OP 决议 100% 有行动项、有跟踪、有闭环。
3. 供应商协同：TOP50 供应商订单确认率 ≥ 95%，ASN 到达率 ≥ 90%。
4. 准时交付：TOP50 供应商准时交付率 ≥ 95%，延期有预警。
5. 库存：库存周转从 45 天降到 30 天，缺料停线 ≤ 4 小时/月。
6. 三单匹配：采购订单、收货、发票匹配率 ≥ 98%，差异 3 日内解决。
7. 集成：SCM 停 2 小时，采购订单和收货不受影响，恢复后补传。
8. 风险：单一来源物料 100% 有备选方案或安全库存。

## 二、高频问答：会卡住你的地方，也是面试最常问的

### 2.1 SCM 就是采购系统

**现场**

问三个问题：需求预测谁做、库存策略谁定、缺料风险谁预警。三个都没答案，就是采购系统。

**要点**

- SCM 的核心是需求计划、供需平衡、库存优化、风险管控。
- 采购只是执行层。
- 把 SCM 当采购系统，会丢掉最有价值的预测和协同能力。

**追问**

- SCM 和 ERP 怎么分工？→ SCM 管跨企业协同和计划决策，ERP 管交易和账务。
- 采购在 SCOR 里对应哪个流程？→ Source，只是五个流程之一。
- SCM 不管什么？→ 财务过账、车间领料、库位作业都不归它。

### 2.2 预测不准是算法问题

**现场**

看有没有预测版本、责任人、偏差复盘，没有就先补机制再谈算法。

**要点**

- 预测不准多半是无人负责、无误差跟踪、无复盘。
- 算法再好，输入是拍脑袋也没用。
- 预测要版本化：每周一个版本，记录预测值、实际值、偏差。

**追问**

- 预测准确率该考核谁？→ 计划和销售一起，只统计不考核永远不准。
- 偏差超阈值怎么处理？→ 复盘原因，不是直接把数字改掉。
- 什么场景只能靠人判断？→ 新品和大项目，定性预测加客户计划。

### 2.3 安全库存一刀切

**现场**

先做 ABC-XYZ 分类，看 AX 和 CZ 是不是用了同一套策略。

**要点**

- 不同物料的需求稳定性和价值差异巨大，一刀切会同时造成积压和缺料。
- ABC 按消耗金额分，XYZ 按需求稳定性分。
- AX 类可以降库存，CZ 类要保安全库存。

**追问**

- 安全库存怎么算？→ Z × σ × √L，前提是需求和提前期的波动能测出来。
- 提前期不准会怎样？→ 公式再对也没用，先验证提前期是否可靠。
- 所有低值物料都要备货吗？→ 定期检查补货更省事，别硬套再订货点。

### 2.4 供应商协同就是上个门户

**现场**

看订单确认率、ASN 到达率、对账及时率，低于 90% 说明协同没跑起来。

**要点**

- 协同要有激励和闭环：响应率纳入份额分配，数据质量纳入考核。
- 没有激励，供应商不会认真维护数据。
- 门户只是载体，不是协同本身。

**追问**

- 协同分几层？→ 订单协同、物流协同、库存协同、计划协同，成熟度依次升高。
- 供应商为什么不愿共享真实数据？→ 缺信任，也缺利益分配机制。
- ASN 有什么用？→ 仓库能提前预约和预分配，收货不用全靠人工清点。

### 2.5 运费算不清是财务的事

**现场**

抽查 20 单运费，看是否和计费规则一致，差异大就是没管。

**要点**

- 运费规则复杂：重量、体积、距离、附加费。
- 不算清就无法比价、优化线路、识别异常。
- 运费管理三件事：计费规则、对账、异常处理。

**追问**

- 只盯运费为什么不够？→ 要看总成本，仓储、库存持有、缺货成本都算进去。
- 运单和结算对不上怎么查？→ 按计费规则逐项拆，看重量、体积、距离哪一项差。
- 3PL 怎么管？→ 合同、KPI、运费结算三条线一起看。

### 2.6 库存越少越好

**现场**

看缺料停线时间和客户准时交付率，库存降了但这两个恶化了，说明降过头了。

**要点**

- 库存是缓冲，过低会让缺料风险和停线成本上升。
- 目标是服务水平约束下的最低总成本，不是零库存。
- 把库存推给上游或下游，总成本没降，只是转移了。

**追问**

- 库存周转怎么降？→ 先分 ABC-XYZ，再压提前期和清呆滞，不要一刀切砍量。
- 精益的零库存适合什么场景？→ 需求稳定、供应商近、协同好的场景。
- 安全库存和周转率冲突吗？→ 冲突，所以按物料分类分别定策略。

### 2.7 VMI 是万能药

**现场**

问三件事：需求数据共享吗、结算规则清吗、供应商财务健康吗。三个都是否，VMI 会变成新的风险。

**要点**

- VMI 要求数据透明、协同深入、结算清晰。
- 供应商的风险最终仍会传导给企业。
- VMI 降低的是库存压力，不是消除风险。

**追问**

- VMI 和寄售的区别？→ VMI 是供应商管补货到约定水位，寄售是货在供应商名下、用时才结算。
- VMI 最容易在哪出问题？→ 结算口径和需求数据不透明。
- 寄售的风险在哪？→ 账务和税务处理。

### 2.8 单一来源只看价格

**现场**

看有没有备选供应商、财务健康度、合规记录，没有就要做风险预案。

**要点**

- 单一来源有断供、议价、质量风险，低价可能伴随高风险。
- 高风险、高价值物料建议双源。
- 双源的代价是可能损失批量折扣。

**追问**

- 双源一定比单源好吗？→ 不一定，看物料风险和批量折扣怎么权衡。
- 单一来源物料怎么兜底？→ 备选方案或安全库存，验收要求 100% 覆盖。
- 比价该看什么？→ 看 TCO，单价之外还有质量、物流、库存、服务和风险。

### 2.9 供应链数字化就是上系统

**现场**

看 S&OP 决议执行率、供应商协同率、预测准确率，这些不提升，系统就是摆设。

**要点**

- 数字化是数据透明、决策机制、协同激励三件事，系统只是载体。
- 没有机制，系统只是电子表格。
- 控制塔解决“看得见”，前提是数据已经打通。

**追问**

- S&OP 做到第几级算有效？→ 至少到数据统一、决议执行，不是有例会就算。
- 为什么先做机制再上系统？→ 机制不清，系统只会把各说各话固化下来。
- 预测准确率上不去，上系统有用吗？→ 没用，先补责任人和偏差复盘。

### 2.10 只管自己的库存

**现场**

看供应链总成本：库存 + 缺料 + 运费 + 质量，不是单个企业的库存成本。

**要点**

- 供应链是链条，把库存推给上游或下游，总成本没降，只是转移了成本。
- 牛鞭效应会让需求信息沿链条向上游逐级放大。
- 缓解靠信息共享、缩短提前期、稳定订货。

**追问**

- 牛鞭效应怎么来的？→ 需求信息逐级放大，上游库存远高于实际需求。
- 推式和拉式怎么选？→ 通用件推、定制件拉，混合策略最常见。
- 韧性 vs 效率怎么权衡？→ 效率把缓冲压到极限，韧性要求留冗余，是权衡不是倒退。

## 三、核心知识

### 3.1 SCM 的定位

SCM（Supply Chain Management）管理从需求产生到产品交付的全链路，覆盖计划、采购、制造协同、物流、库存、退货。

核心目标：**在给定服务水平下，最小化总成本（库存 + 缺料 + 运费 + 质量）**。

### 3.2 SCOR 模型

SCOR（Supply Chain Operations Reference）把供应链分为五个流程：

| 流程 | 内容 |
|---|---|
| Plan | 需求、供给、S&OP |
| Source | 寻源、采购、供应商管理 |
| Make | 生产、排产、执行 |
| Deliver | 订单、仓储、运输、交付 |
| Return | 退货、逆向物流 |
| Enable | 数据、系统、合规 |

SCOR 还定义了一级指标：可靠性、响应性、敏捷性、成本、资产管理。它是评估和改进供应链的通用框架。

> **面试**：常问「SCOR 的五个流程是什么？」答：Plan、Source、Make、Deliver、Return，Enable 做支撑。

### 3.3 需求预测

| 方法 | 公式/思路 | 适用 |
|---|---|---|
| 移动平均 | 近 N 期平均 | 平稳 |
| 指数平滑 | 加权近期 | 有趋势 |
| Holt-Winters | 趋势 + 季节 | 季节性明显 |
| 回归 | 关联驱动因素 | 有促销/价格因子 |
| 协同预测 | 客户共享计划 | 大客户 |

预测评估指标：MAPE、偏差、跟踪信号。预测要版本化，每次调整留痕。

### 3.4 S&OP

S&OP 的五个成熟度等级：

| 等级 | 特征 |
|---|---|
| 1 无 | 没有正式 S&OP |
| 2 被动 | 事后救火 |
| 3 主动 | 有例会，缺闭环 |
| 4 受控 | 数据统一，决议执行 |
| 5 协同 | 与供应商/客户协同 |

S&OP 的核心产出：一致的需求版本、供给能力、库存策略、行动项。

> **面试**：常问「S&OP 和 IBP 有什么区别？」答：IBP 是 S&OP 的扩展，加入财务和战略维度。

### 3.5 库存模型

| 模型 | 公式 | 适用 |
|---|---|---|
| EOQ | √(2DS/H) | 需求稳定、批量折扣 |
| 再订货点 | ROP = 日均需求 × 提前期 + 安全库存 | 需求稳定 |
| 安全库存 | SS = Z × σ × √L | 需求波动 |
| 定期检查 | 固定周期补货 | 低值、易采购 |

不要盲目套公式。先验证需求是否稳定、提前期是否可靠，再选模型。

> **面试**：常问「EOQ 公式能直接拿来定采购批量吗？」答：它假设需求稳定、无产能约束，真实场景要用启发式或仿真。

### 3.6 供应商协同

| 模式 | 共享内容 | 成熟度 |
|---|---|---|
| 订单协同 | 订单、确认、变更 | 基础 |
| 物流协同 | ASN、预约、跟踪 | 中 |
| 库存协同 | VMI、寄售 | 高 |
| 计划协同 | CPFR、共享预测 | 最高 |

协同的前提是“数据标准 + 激励 + 信任”。没有信任，供应商不会共享真实数据。

### 3.7 物流

物流成本构成：

| 成本 | 说明 |
|---|---|
| 运输费 | 整车、零担、快递 |
| 仓储费 | 仓租、操作 |
| 库存持有 | 资金、损耗、保险 |
| 缺货成本 | 停线、加急、客诉 |
| 管理成本 | 系统、人力 |

优化方向：线路优化、集货配载、运输模式选择、承运商比价。不要只盯运费，要看总成本。

### 3.8 风险管理

| 风险 | 识别 | 应对 |
|---|---|---|
| 断供 | 单一来源、供应商财务 | 备选、安全库存 |
| 价格波动 | 大宗商品 | 长期协议、套保 |
| 质量 | 来料合格率 | 供应商改善、驻厂 |
| 物流 | 天气、关务、疫情 | 多式联运、提前备货 |
| 合规 | 环保、劳工、制裁 | 准入审核、定期审计 |
| 汇率 | 外币采购 | 锁汇、本地化 |

风险要“量化 + 预案 + 演练”，不是“写进报告就算管了”。

### 3.9 集成

SCM 与周边系统的关系：

- ERP：订单、库存、财务；
- WMS：收货、发货、库位；
- MES：消耗、完工；
- BI：绩效、成本、风险；
- 外部：供应商、承运商、客户、海关。

原则：SCM 管“跨企业协同和计划决策”，ERP 管“交易和账务”，WMS 管“实物作业”。

### 3.10 指标体系

| 一级指标 | 二级指标 |
|---|---|
| 可靠性 | 准时交付率、订单履约率 |
| 响应性 | 订单周期、预测准确率 |
| 敏捷性 | 换产时间、恢复时间 |
| 成本 | 库存周转、采购成本、运费占比 |
| 资产管理 | 库存天数、呆滞率 |

指标要能下钻到物料、供应商、区域，才能指导行动。

## 四、冷门知识汇总

- **SCOR 模型**：APICS 提出的供应链参考模型，五个流程（Plan、Source、Make、Deliver、Return）+ Enable。它是一级指标和流程改进的通用语言。
- **CPFR（协同计划、预测与补货）**：供应链协同的高级形态，企业与客户/供应商共享预测和补货计划。它要求数据透明和利益分配机制。
- **VMI（供应商管理库存）**：供应商负责补货到约定水位，企业按消耗结算。它降低企业库存压力，但要求需求数据透明和结算规则清晰。
- **寄售（Consignment）**：货在供应商名下，企业用时才结算。适合高价值、长周期物料；风险在账务和税务处理。
- **EOQ 的局限**：假设需求稳定、批量折扣简单、无产能约束。真实场景要用启发式或仿真。
- **牛鞭效应（Bullwhip Effect）**：需求信息沿供应链向上游逐级放大，导致上游库存远高于实际需求。缓解方法是信息共享、缩短提前期、稳定订货。
- **推式与拉式**：推式按预测生产，拉式按订单生产。混合策略（推通用件、拉定制件）是常见最优解。
- **S&OP 与 IBP**：IBP（Integrated Business Planning）是 S&OP 的扩展，加入财务和战略维度。很多企业做的是 S&OP，说的是 IBP。
- **MTS/MTO/ATO/ETO**：按库存生产、按订单生产、按订单装配、按订单设计。生产模式决定计划深度和库存策略。
- **Lead Time 的构成**：采购提前期 = 供应商生产时间 + 运输时间 + 检验时间 + 入库时间。压缩任何一段都能降库存，但优先级不同。
- **TCO（总拥有成本）**：采购成本不只是单价，还包括质量、物流、库存、服务、风险。比价要看 TCO。
- **双源与多源**：双源降低断供风险，但可能损失批量折扣。高风险、高价值物料建议双源。
- **本地化与全球化**：本地采购响应快、运费低，但可能成本高；全球化成本低，但风险和提前期长。要按物料特性分层决策。
- **绿色供应链**：碳足迹、包装回收、合规（如欧盟电池法规、冲突矿产）。它从“加分项”变成“准入项”。
- **贸易合规**：出口管制、制裁名单、原产地规则、关税。跨境供应链的合规风险可能让整批货被扣。
- **供应链控制塔**：实时可视化 + 预警 + 决策支持。它解决“看得见”，但前提是数据已经打通。
- **韧性 vs 效率**：追求效率会把库存和冗余压到极限，韧性要求保留缓冲。疫情后很多企业从“just-in-time”转向“just-in-case”，这是权衡，不是倒退。
