妙妙屋站点 · 部署拓扑 v1.0.0

一个静态站点，三段链路：GitHub 拉代码 → Cloudflare 构建 → 边缘分发。无自建服务器、无数据库、无中间件。

发布链路 访问链路 本地依赖，非生产链路

三段链路，一条关键判断

  • GitHub → 构建机：推 master 触发 webhook，Cloudflare 拉代码跑 npm run build。
  • 构建机 → 边缘：产物上传到全球 CDN，读者从最近节点拿 HTML。
  • 内容源仓库不在生产链路上（橙色虚线）。线上不跑 sync，因为构建环境里没有那两个目录。所以源库挂了，站点照常服务。
节点类型挂了会怎样能做什么
GitHub代码托管 + 触发无法发布新版本；线上旧版仍可访问等恢复，或手工上传产物
Cloudflare 构建机CI发布失败；线上保持上一版查 Deployments 日志，修后重推
Cloudflare 边缘CDN站点不可访问无备份托管，等恢复
两个内容源仓库本地内容来源不影响线上本地已有产物，可直接构建
